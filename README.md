# Kuruba Somesh — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `somesh-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.
